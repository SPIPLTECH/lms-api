# Primitive Types at a Glance

| Type | Typical size | Holds |
| --- | --- | --- |
| `char` | 1 byte | A single character |
| `int` | 4 bytes | Whole numbers |
| `float` | 4 bytes | Approximate decimals |
| `double` | 8 bytes | Higher-precision decimals |
